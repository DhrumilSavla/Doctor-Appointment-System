# Doctor-Appointment-System

Monorepo containing:

| Folder      | Stack              | Dev URL                 |
| ----------- | ------------------ | ----------------------- |
| `frontend/` | Next.js (App Router, TypeScript) | http://localhost:3000 |
| `backend/`  | NestJS (TypeScript) | http://localhost:3001 |

## Getting started

```bash
# Frontend
cd frontend
npm install
npm run dev

# Backend (in a second terminal)
cd backend
npm install
npm run start:dev
```
